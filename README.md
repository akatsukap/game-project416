# 🃏 Table Game Project (仮)

トランプや人狼ゲームをブラウザで遊べるようにするプロジェクトです。

## 🚀 このゲームについて
- **ジャンル**: テーブルゲーム（トランプ・人狼）※企画中
- **プラットフォーム**: ウェブブラウザ（PC/スマホ）
- **開発状況**: 企画・開発初期フェーズ

> 📝 **現在の状況**: ゲームの具体的な仕様を議論中です。詳細は [ゲーム企画書](docs/GAME_DESIGN.md) をご覧ください。

## 🛠 使用技術
- **言語**: HTML / CSS / JavaScript
- **公開環境**: GitHub Pages

## 📂 フォルダ構成
- `index.html`: ゲームのメイン画面
- `docs/`: プロジェクトドキュメント
  - [GAME_DESIGN.md](docs/GAME_DESIGN.md): ゲーム企画書
  - [CONTRIBUTING.md](docs/CONTRIBUTING.md): 開発ガイド
- `assets/`: 画像や音声ファイル（今後追加）
- `js/`: ゲームのロジック（プログラム）（今後追加）
- `css/`: デザイン設定（今後追加）

## 📝 開発の進め方
1. `main` ブランチから機能ごとにブランチを作成して作業する
2. 作業が終わったら Pull Request を作成する
3. メンバーの確認後、`main` にマージする

詳細な開発ガイドは [CONTRIBUTING.md](docs/CONTRIBUTING.md) をご覧ください。
