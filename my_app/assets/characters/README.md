# キャラクタースプライト

このディレクトリには、ヘッドボールゲームで使用するキャラクタースプライト画像が格納されます。

## 必要な画像ファイル

以下の5つのキャラクター画像が必要です：

1. **hero1.png** - 地元のヒーロー（青色、スピード型）
   - 特殊能力: スピードブースト ⚡
   - 速度: 100.0 / ジャンプ: 300.0 / キック: 500.0

2. **shop_owner.png** - 商店のおやじ（赤色、パワー型）
   - 特殊能力: パワーキック 💪
   - 速度: 80.0 / ジャンプ: 250.0 / キック: 700.0

3. **student.png** - 地元の学生（緑色、テクニック型）
   - 特殊能力: 時間停止 ⏱️
   - 速度: 120.0 / ジャンプ: 280.0 / キック: 450.0

4. **firefighter.png** - 地元の消防士（黄色、ジャンプ型）
   - 特殊能力: ジャンプブースト 🚀
   - 速度: 90.0 / ジャンプ: 400.0 / キック: 550.0

5. **security_guard.png** - 地元の警備員（紫色、防御型）
   - 特殊能力: シールド 🛡️
   - 速度: 85.0 / ジャンプ: 270.0 / キック: 480.0

## 画像仕様

- **形式**: PNG（透過背景推奨）
- **推奨サイズ**: 128x128 ピクセル
- **スタイル**: シンプルなキャラクターデザイン
- **向き**: 正面または横向き

## プレースホルダー画像の生成

実際の画像が用意できるまで、プレースホルダー画像を生成できます。

### 方法1: Pythonスクリプト（推奨）

```bash
# Pillowライブラリをインストール
pip install pillow

# スクリプトを実行
python3 generate_placeholders.py
```

このスクリプトは、各キャラクターの特徴を反映したシンプルな画像を生成します：
- キャラクターごとに異なる色
- 簡単な人型シルエット
- 能力名のラベル

### 方法2: Dartスクリプト

```bash
# 最小限のPNG画像を生成
dart run create_minimal_pngs.dart
```

このスクリプトは、1x1ピクセルの透明PNG画像を生成します（開発用の最小限のプレースホルダー）。

### 方法3: 手動作成

画像編集ソフト（GIMP、Photoshop、Procreateなど）を使用して、各キャラクターの画像を作成してください。

## デザインガイドライン

### キャラクターの特徴を反映

各キャラクターの能力や個性が視覚的に分かるようにデザインしてください：

- **地元のヒーロー**: スポーティーな服装、動きのあるポーズ
- **商店のおやじ**: がっしりした体格、エプロン姿
- **地元の学生**: 学生服、軽快な印象
- **地元の消防士**: 消防服、ヘルメット
- **地元の警備員**: 制服、安定感のある立ち姿

### 色使い

各キャラクターには推奨カラーがあります：

| キャラクター | メインカラー | RGB値 |
|------------|------------|-------|
| 地元のヒーロー | 青 | (52, 152, 219) |
| 商店のおやじ | 赤 | (231, 76, 60) |
| 地元の学生 | 緑 | (46, 204, 113) |
| 地元の消防士 | 黄 | (241, 196, 15) |
| 地元の警備員 | 紫 | (155, 89, 182) |

## 著作権とライセンス

## トラブルシューティング

### 画像が表示されない

1. ファイル名が正確か確認（大文字小文字を区別）
2. ファイルがこのディレクトリに配置されているか確認
3. `pubspec.yaml`でアセットが登録されているか確認
4. `flutter pub get`を実行してアセットを更新
5. アプリを再起動（ホットリロードでは反映されない場合がある）

### 画像が歪む

- 元画像のアスペクト比を確認
- 推奨サイズ（128x128）で作成
- ゲーム内でのスケーリング設定を確認

### パフォーマンスの問題

- 画像サイズを最適化（不要に大きくしない）
- PNG圧縮ツールを使用（TinyPNG、OptiPNGなど）
- 必要に応じてスプライトアトラスを検討
