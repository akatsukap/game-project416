# キャラクタープレースホルダー画像生成手順

## クイックスタート

アプリを動作させるために、最低限のプレースホルダー画像を生成します。

### オプション1: Pythonスクリプト（推奨）

最も見栄えの良いプレースホルダーを生成します。

```bash
# 1. Pillowライブラリをインストール
pip install pillow

# 2. このディレクトリに移動
cd my_app/assets/characters

# 3. スクリプトを実行
python3 generate_placeholders.py
```

**生成される画像**:
- 各キャラクターの色分け
- シンプルな人型シルエット
- 能力名のラベル付き
- 64x64ピクセルのPNG画像

### オプション2: Dartスクリプト

最小限の透明PNG画像を生成します（開発用）。

```bash
# このディレクトリに移動
cd my_app/assets/characters

# スクリプトを実行
dart run create_minimal_pngs.dart
```

**生成される画像**:
- 1x1ピクセルの透明PNG
- アプリのクラッシュを防ぐための最小限のファイル

### オプション3: 手動作成

画像編集ソフトで手動で作成する場合：

1. 以下のファイルを作成:
   - `hero1.png`
   - `shop_owner.png`
   - `student.png`
   - `firefighter.png`
   - `security_guard.png`

2. 各ファイルの推奨仕様:
   - サイズ: 128x128 ピクセル
   - 形式: PNG（透過背景）
   - 内容: シンプルなキャラクターデザイン

以下の5つのファイルが存在することを確認:
- hero1.png

## トラブルシューティング

### エラー: "Asset not found"

**原因**: 画像ファイルが存在しないか、パスが間違っている

**解決方法**:
1. ファイルが正しいディレクトリにあるか確認
2. ファイル名が正確か確認（大文字小文字を区別）
3. `flutter clean` を実行
4. `flutter pub get` を実行
5. アプリを再起動

### エラー: "Unable to load asset"

**原因**: pubspec.yamlでアセットが登録されていない

**解決方法**:
`my_app/pubspec.yaml` を確認し、以下が含まれていることを確認:

```yaml
flutter:
  assets:
    - assets/characters/
```

### 画像が表示されない

**原因**: ホットリロードでは新しいアセットが反映されない

**解決方法**:
1. アプリを完全に停止
2. `flutter run` で再起動

### Pythonスクリプトが実行できない

**原因**: Pillowライブラリがインストールされていない

**解決方法**:
```bash
# pip を使用
pip install pillow

# または pip3 を使用
pip3 install pillow

# または conda を使用
conda install pillow
```

## 次のステップ

### 本格的な画像の作成

プレースホルダーが動作したら、本格的なキャラクター画像を作成しましょう：

1. **デザインツールの選択**:
   - GIMP（無料）
   - Krita（無料）
   - Photoshop（有料）
   - Procreate（iPad、有料）

2. **デザインガイドライン**:
   - 各キャラクターの個性を反映
   - 推奨カラーを使用
   - シンプルで認識しやすいデザイン
   - 透過背景を使用

3. **アニメーション対応**（将来的）:
   - スプライトシートの作成
   - 各アクションのフレーム作成
   - Flameのアニメーション機能と統合

### フリー素材の活用

自分で作成しない場合は、フリー素材を活用できます：

1. [OpenGameArt.org](https://opengameart.org/) で検索
2. ライセンスを確認（CC0、CC-BY推奨）
3. ダウンロードして適切にリサイズ
4. 必要に応じて色を変更

### デザイナーへの依頼

プロフェッショナルな仕上がりを求める場合：

1. デザイン仕様書を作成
2. 各キャラクターの特徴を明確に
3. 参考画像を用意
4. 納品形式を指定（PNG、サイズ、透過など）

## よくある質問

**Q: プレースホルダーのままでもゲームは動作しますか？**
A: はい、動作します。ただし、見た目は簡素です。

**Q: 画像のサイズは変更できますか？**
A: はい。ただし、アスペクト比を保つことを推奨します。

**Q: アニメーションは必要ですか？**
A: 現時点では不要です。静止画のみで動作します。

**Q: 商用利用は可能ですか？**
A: 自作の画像またはライセンスを確認したフリー素材を使用してください。
