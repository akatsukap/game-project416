# エフェクトアセット

このディレクトリには、特殊能力やゲームイベントで使用される
視覚エフェクトのスプライトが含まれています。

## 必要なスプライト

### 特殊能力エフェクト

1. **speed_boost.png** - スピードブーストエフェクト
   - 推奨サイズ: 64x64ピクセル
   - 色: 青色の光の軌跡

2. **power_kick.png** - パワーキックエフェクト
   - 推奨サイズ: 64x64ピクセル
   - 色: 赤色の衝撃波

3. **time_stop.png** - 時間停止エフェクト
   - 推奨サイズ: 64x64ピクセル
   - 色: 紫色の時計マーク

4. **jump_boost.png** - ジャンプブーストエフェクト
   - 推奨サイズ: 64x64ピクセル
   - 色: オレンジ色の上向き矢印

5. **shield.png** - シールドエフェクト
   - 推奨サイズ: 64x64ピクセル
   - 色: 緑色の盾

### パーティクル

6. **particle.png** - 汎用パーティクル
   - 推奨サイズ: 8x8ピクセル
   - 色: 白色の小さな円

## プレースホルダー画像について

現在のスプライトは開発用のプレースホルダーです。
実際のゲームリリース時には、プロのデザイナーが作成した
高品質なエフェクトアニメーションに置き換える必要があります。

## 画像フォーマット

- フォーマット: PNG（透過背景必須）
- 解像度: @2x, @3x バリアントも用意することを推奨
- アニメーション: スプライトシートまたは個別フレーム
